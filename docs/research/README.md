# Research findings

Primary-source findings produced by `map-scout` agents while working the [wayfinder map](https://github.com/zhipengzhu1-dotcom/10-Sep-2026-LIMS/issues/1).

One file per question, named for the question. Each records what was asked, who asked, which version of each source was checked, what was found with every claim cited, and what the sources did not settle.

These are **facts gathered, not decisions made**. A scout never recommends what Benchline should do — decisions live in their tickets and are indexed on the map. If a file here reads like a recommendation, it is out of role.

Public regulatory and standards text is in scope. No real laboratory documents, client names, product names, batch identifiers or results — here or anywhere else in this repository.
